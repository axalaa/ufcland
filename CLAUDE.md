# CLAUDE.md — правила работы над проектом «UFC ქართულად»

Этот файл Claude читает в начале каждой сессии. Держим его коротким.

## Что за проект
Грузиноязычный фан-лендинг про UFC: поиск бойцов, статистика, меню весовых
категорий, профиль бойца (биография + история боёв с метками
«ფავორიტი / აუტსაიდერი / თანაბარი» — фаворит / андердог / равные шансы).

Главный и почти единственный файл — **`index.html`**: один самодостаточный файл
(HTML + CSS + весь JS + данные бойцов внутри). Внешние библиотеки — с CDN
(сейчас только шрифт Noto Sans Georgian). Сборщиков, фреймворков, npm — нет.

## Публикация
Сайт живой: **https://axalaa.github.io/ufcland/**
Хостинг — GitHub Pages, репозиторий `axalaa/ufcland` (публичный), ветка `master`,
папка `/(root)`. **Обновление сайта = `git push`**, GitHub пересобирает за 1–3 мин.
Главный файл обязан называться `index.html` — иначе не откроется по короткому адресу.
Свой домен пока не куплен; когда появится — подключается к этому же сайту,
старый адрес продолжит работать.

## Как работать (принципы)
1. **Думать до кода.** Перед изменением кратко проговори план и риски.
   Пользователь — новичок, поэтому объясняй *почему*, а не только *что*.
   Общение — по-русски.
2. **Сначала простота.** Минимум кода, без фич «про запас» и лишних зависимостей.
   Читаемость важнее «крутизны» — это учебный проект.
3. **Хирургические правки.** Меняй только нужное, не переписывай файл целиком.
4. **Цель с проверкой.** Для каждой фичи заранее договаривайся, *как поймём,
   что она работает*, и в конце давай короткий список «проверь 1/2/3».

## Что важно знать про код
- **Интерфейс — на грузинском.** Новые тексты для игрока пиши по-грузински,
  в тон существующим. Комментарии в коде — по-русски (для обучения).
- **Все цвета** — в CSS-переменных в `:root` вверху `<style>`. Тема тёплая
  тёмная (уголь + красный + золото). Крути оттенки там.
- **Бойцы** хранятся в массиве `FIGHTERS` вверху `<script>`: один боец = один
  объект. Чтобы добавить — копируешь блок и меняешь поля. У каждого боя
  `role`: `'favorite' | 'underdog' | 'even'`.
- **Весовые категории** — в массиве `WEIGHT_CLASSES`. Названия оставляем
  английскими (`Lightweight` и т.д.) — это общепринятые термины, решено не переводить.
- **У всех 64 бойцов есть `details`** — факты (`born`/`birthplace`/`team`/`style`),
  `nickFrom` (откуда прозвище) и проза в поле `text` (абзацы через `\n\n`).
  Нового бойца добавлять сразу с `details` по этому образцу.
- **Флаги** — не эмодзи, а SVG-спрайт в начале `<body>` (Windows эмодзи-флаги не
  рисует). В данных остаётся эмодзи, подменой занимается `flagIcons()`.
  Новая страна = дописать `<symbol id="fl-XX">` и код в `FLAG_CODES`.
- **Рейтинг P4P** — массив `P4P` (порядок = места 1–15) и дата в `P4P_DATE`
  рядом с `WEIGHT_CLASSES`. Обновляется перестановкой id.
- **Ближайший турнир** — объект `NEXT_CARD` там же. Открывается кнопкой «Next Card»
  в шапке. Турнир прошёл = заменить блок целиком на следующий (даты и составы
  сверять по Wikipedia). Имя бойца САМО становится ссылкой, если он есть в
  `FIGHTERS`; кого нет — остаётся текстом, добавлять заранее никого не нужно.
  Категория (`div`) — строкой, потому что в кардах бывают категории, которых нет
  в нашем меню (например женские). Апостроф в `"Women's Strawweight"` = двойные кавычки.
- **Вход и облако — Firebase**, проект `ufcland-b9dea`. Вход только через Google,
  паролей не храним вообще. Модуль лежит в конце `<body>` отдельным `type="module"`
  и общается с основным скриптом через `window.FBAuth` (войти/выйти),
  `window.FBData` (база) и `window.onAuthChange` (Firebase зовёт сам).
  В Firestore два раздела с разными правами: `users/{uid}` — избранное, читает и
  пишет только владелец; `scores/{uid}` — рекорд квиза, читают все (ради общего
  топ-5), пишет только владелец. Данные аккаунта выкачиваются **один раз при входе**
  в `userData`, чтобы отрисовка осталась синхронной — не ходи в базу из render-функций.
  ⚠️ Новый домен (свой сайт) = добавить в Firebase → Authentication → Settings →
  Authorized domains, иначе вход молча не сработает. Локально (`file://`) вход
  не проверить — Google пускает только с http(s), тестировать на живом сайте.
- **Апостроф в имени = экранировать!** Строки в данных в одинарных кавычках,
  поэтому имя с апострофом (напр. `Sean O'Malley`) надо писать как
  `'Sean O\'Malley'`. Неэкранированный апостроф обрывает строку и роняет ВЕСЬ
  скрипт — на сайте пропадают все бойцы/категории/статистика. (Уже ловили этот баг.)
- **Актуальность данных — обязательна.** Рекорды, даты, статусы бойцов быстро
  меняются, а встроенные знания модели устаревают (есть cutoff). Перед тем как
  вписывать/обновлять бойца — проверяй через веб-поиск (Wikipedia / ufc.com) и
  бери самые свежие данные. Пример: Топурия — 17-1 (проиграл Гэтжи 14.06.2026),
  а не 16-0. Стартовые данные были демонстрационными — постепенно заменяем
  выверенными.
- **Видео хайлайтов** в герое: в `.hero-media` лежит заглушка `.hero-poster`.
  Чтобы вставить реальное видео — положить файл рядом (напр. `topuria.mp4`),
  удалить заглушку и раскомментировать `<video>` (см. комментарий в коде).

## В планах (по договорённости с пользователем)
- **Бойцов под ближайшие карды добавляем постепенно**, по мере надобности —
  расписание базу не ждёт. Из UFC 330 добавлен только Machado Garry (претендент
  на пояс), остальные 22 участника пока текстом. Женщин в базе нет и женских
  категорий в меню нет — решено не открывать это направление пока.
- **Добавить грузина Чохели (Chokheli)** — когда появится достаточно выверенной
  публичной инфы (сейчас данных мало).
- **ИИ-чат** — сейчас `askAgent()` возвращает демо-ответ. Настоящий требует своего
  мини-сервера (ключ нельзя держать в `index.html`) и стоит денег за каждый вопрос.
  Делать последним; доступ только вошедшим + лимит вопросов в день.
- Мелочи: котировки боёв видны только как tooltip (на телефоне не видны вообще);
  у длинных имён чемпионов флаг переносится на отдельную строку.

## Проверка
Запускать сайт автоматически нельзя (нужен браузер). После изменений не утверждай
«работает» — давай чёткие шаги для ручной проверки и жди результат пользователя.
Открыть локально: `start index.html`.
